# Sistema de Locadora de Veículos

![Demonstração do Projeto](https://i.imgur.com/WYtRkEM.gif)

## Descrição
Sistema para gerenciamento de locação de veículos (automóveis, vans e motos), cobrindo desde o cadastro e locação até a venda final.

## Tecnologias
- Java
- Swing
- JDBC
- PostgreSQL

## Arquitetura
O projeto utiliza o padrão MVC (Model-View-Controller) para organização do código e o padrão DAO (Data Access Object) para persistência de dados. A estrutura faz uso de orientação a objetos com herança e polimorfismo para os diferentes tipos de veículos.
